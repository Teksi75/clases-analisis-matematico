Java paso a paso: juego de adivinar un número

Vamos a construir un programa que elige un número secreto del 1 al 100, permite hasta 10 intentos y da pistas. No hace falta memorizar Java de golpe: primero entendemos cada concepto y después lo usamos.

1. Qué tiene que hacer el programa

La consigna del ejercicio se puede escribir así, en lenguaje común:

Objetivo: crear una aplicación que genere un número entero aleatorio entre 1 y 100. La persona ingresa números para adivinarlo. Después de cada intento incorrecto, el programa indica si el número secreto es mayor o menor que el ingresado y cuántos intentos quedan. Hay como máximo 10 intentos.

Entonces el programa necesita cuatro acciones centrales: preparar datos, pedir un número, comparar y repetir solo mientras corresponda.

  • Si acierta, muestra éxito y termina.
  • Si falla, muestra una pista y los intentos restantes.
  • Si usa los 10 intentos sin acertar, muestra derrota y no pide un intento número 11.

Supuesto para esta clase: cada entrada será un número entero. Si alguien escribe texto, deja vacío o pone un decimal, eso se resuelve con validación de entrada más adelante; no lo implementamos hoy.

2. Nombres que vamos a usar

Elegimos nombres claros y los repetimos siempre igual. En Java no conviene escribir nombres con espacios ni símbolos como “n°”.

NombreQué representaEjemplo cotidiano
secretoEl número que el programa sortea y que hay que adivinar.La respuesta guardada en una tarjeta tapada.
numeroUsuarioEl número que la persona escribe en un intento.La apuesta de esa ronda.

3. Fundamentos mínimos antes del código largo

  1. int: tipo de dato para números enteros, como 1, 42 o 100. No representa texto ni decimales.
  2. Declarar: crear una variable con tipo y nombre. int intentos; significa “voy a tener una variable entera llamada intentos”.
  3. Asignar: guardar un valor con =. intentos = 0; significa “guardá 0 en intentos”. También se puede declarar y asignar en una misma línea: int intentos = 0;.
  4. Comparar igualdad: preguntar con ==. numeroUsuario == secreto no guarda nada: pregunta si ambos valores son iguales.
  5. boolean: tipo de dato que solo puede valer true o false. Nos sirve para recordar si ya se adivinó.
  6. !: niega un booleano. Si adivino vale false, entonces !adivino vale true: “no adivinó todavía”.
  7. &&: significa “y”. Para que intentos < 10 && !adivino sea verdadero, tienen que cumplirse las dos partes.
  8. Condiciones: expresiones que responden verdadero o falso, por ejemplo intentos < 10 o numeroUsuario > secreto.
  9. Llaves { }: agrupan instrucciones. Todo lo que está dentro de las llaves de un while se repite; todo lo que está dentro de las llaves de un if pertenece a esa decisión.
  10. System.out.println(...): muestra un mensaje en pantalla y baja a la línea siguiente. Algunos entornos permiten escribir sout como abreviatura para completarlo automáticamente; es solo un atajo opcional.

4. Construimos el programa de a poco

Los siguientes fragmentos son parciales: sirven para entender una pieza. No todos compilan solos porque algunos dependen de líneas que veremos después.

Fragmento 1 · Salida por pantalla

Primero mostramos la consigna. El texto va entre comillas porque es texto literal.

  1. System.out.println("Adiviná el número secreto entre 1 y 100.");

En lenguaje cotidiano: “mostrá esta frase en la consola”.

Fragmento 2 · Herramientas: Scanner, Random, new e import

Java trae muchas herramientas, pero algunas hay que pedirlas con import. Para este juego usamos dos:

  • Scanner: lee datos que entran por teclado.
  • Random: genera números al azar.
  1. import java.util.Random;
  2. import java.util.Scanner;
  4. Scanner teclado = new Scanner(System.in);
  5. Random r = new Random();

new construye una herramienta concreta para poder usarla. En palabras: “creá un lector llamado teclado” y “creá un generador de azar llamado r”.

Fragmento 3 · Número secreto del 1 al 100

La consigna pide un entero desde 1 hasta 100, incluyendo los extremos.

  1. int secreto = r.nextInt(100) + 1;

r.nextInt(100) puede dar 100 valores posibles: desde 0 hasta 99. Al sumar 1, el menor pasa de 0 a 1 y el mayor pasa de 99 a 100.

Puente: si el sorteo interno da 0, el secreto queda 1. Si da 99, el secreto queda 100. Por eso la línea cumple “del 1 al 100”.

Fragmento 4 · Estado inicial del juego

Antes de empezar, no hubo intentos y todavía no se acertó.

  1. int intentos = 0;
  2. boolean adivino = false;

Mercedes, leé la segunda línea como una oración: “la variable adivino empieza en falso”. Va a cambiar a true solo cuando el número ingresado sea igual al secreto.

Fragmento 5 · Repetir sin pasarse de 10 intentos

El while repite mientras la condición sea verdadera.

  1. while (intentos < 10 && !adivino) {
  2. // acá adentro van las instrucciones de cada intento
  3. }

En lenguaje cotidiano: “mientras se hayan usado menos de 10 intentos y todavía no haya acierto, seguí jugando”. Cuando intentos llega a 10, intentos < 10 es falso; por eso no aparece un intento 11.

Fragmento 6 · Leer un intento y contarlo una sola vez

Cada número entero ingresado cuenta como un intento, incluso si es el número ganador.

  1. System.out.println("Ingresá un número:");
  2. int numeroUsuario = teclado.nextInt();
  3. intentos = intentos + 1;

teclado.nextInt() espera que la persona escriba un entero y lo guarda en numeroUsuario. Después intentos = intentos + 1 toma el valor anterior, le suma uno y lo vuelve a guardar en la misma variable.

Fragmento 7 · Comparar y responder

Después de contar el intento, el programa decide entre tres caminos: acertó, el secreto es mayor, o el secreto es menor.

  1. if (numeroUsuario == secreto) {
  2. adivino = true;
  3. System.out.println("¡Correcto! Lo adivinaste en " + intentos + " intentos.");
  4. } else if (numeroUsuario < secreto) {
  5. System.out.println("El número secreto es mayor. Te quedan " + (10 - intentos) + " intentos.");
  6. } else {
  7. System.out.println("El número secreto es menor. Te quedan " + (10 - intentos) + " intentos.");
  8. }

La pista habla del secreto. Si ingresás 30 y el secreto es 42, la pista útil es “el número secreto es mayor”.

El signo + une texto con valores para armar el mensaje. (10 - intentos) calcula cuántos intentos quedan: si ya usaste 1, quedan 9.

5. Cómo fluye una vuelta completa

1. Revisar condición: ¿intentos < 10 y !adivino?
2. Pedir: si la condición es verdadera, el programa solicita un número.
3. Leer: teclado.nextInt() toma el entero ingresado y lo guarda en numeroUsuario.
4. Contar: intentos = intentos + 1 cuenta exactamente ese intento.
5. Comparar: pregunta si numeroUsuario == secreto, si es menor o si es mayor.
6. Responder: muestra éxito o una pista con intentos restantes.
7. Volver o terminar: vuelve al while. Si acertó o ya llegó a 10 intentos, no vuelve a pedir.

6. Traza trabajada con secreto fijo 42

Importante: usamos 42 solo para practicar la lectura. En el programa real, secreto sale de r.nextInt(100) + 1, así que cambia en cada ejecución.

PasoValorQué pasa
Iniciosecreto = 42, intentos = 0, adivino = falseLa condición del while da verdadera: hay menos de 10 intentos y todavía no se adivinó.
Intento 1numeroUsuario = 30Se cuenta: intentos = 1. Como 30 < 42, imprime “El número secreto es mayor. Te quedan 9 intentos.”
Intento 2numeroUsuario = 42Se cuenta: intentos = 2. Como 42 == 42, cambia adivino = true e imprime éxito.
Salidaadivino = trueLa próxima condición del while falla porque !adivino es falso. No se piden más números.

7. Casos límite que conviene revisar

Acierta en el primer intento

Cuenta 1, muestra éxito y termina. No necesita mostrar intentos restantes porque ya ganó.

Acierta en el décimo intento

Cuenta 10, muestra éxito y termina. No debe mostrar derrota: usó el último intento, pero lo usó bien.

Falla el décimo intento

Cuenta 10, muestra una pista con 0 intentos restantes, sale del while y después muestra derrota.

No hay intento 11

Cuando intentos vale 10, la condición intentos < 10 es falsa. Por eso el ciclo no vuelve a pedir.

Regla de oro: el mensaje final de derrota se escribe como if (!adivino). Así solo aparece si terminó sin acierto.

8. Actividades breves para practicar sola

Actividad A · Leer el rango del azar

Completá mentalmente:

  • Si r.nextInt(100) da 0, entonces r.nextInt(100) + 1 da ____.
  • Si r.nextInt(100) da 99, entonces r.nextInt(100) + 1 da ____.
Ver autocorrección

Da 1 y 100. Por eso el rango final es 1..100.

Actividad B · Trazar intentos

Usá secreto fijo 42 solo para practicar. Entradas: 70, 50, 42. Anotá después de cada entrada: intentos usados, pista o éxito, y si adivino vale true o false.

Ver autocorrección

70: intento 1, secreto menor, adivino = false. 50: intento 2, secreto menor, adivino = false. 42: intento 3, éxito, adivino = true.

Actividad C · Décimo intento

Si ya se hicieron 9 intentos incorrectos y en el décimo se ingresa el secreto correcto, ¿se muestra derrota?

Ver autocorrección

No. El intento 10 cuenta, pero como acierta se guarda adivino = true. El final if (!adivino) no se ejecuta.

9. Lectura por bloques del programa completo

Antes de mirar el código entero, ubicá estas partes:

Imports

Permiten usar Random y Scanner.

Clase y main

public class AdivinarNumero contiene el programa. En el punto 10 vas a ver la línea public static void main(String[] args): es una fórmula fija de arranque que necesita java y ahí empieza la ejecución.

Preparación

Crea teclado, r, secreto, intentos y adivino.

Ciclo

El while controla que no haya más de 10 intentos y que se corte al acertar.

Decisión

El if / else if / else responde éxito, secreto mayor o secreto menor.

Final

if (!adivino) muestra derrota solo cuando realmente no se acertó.

10. Programa completo de referencia

Recién ahora miralo entero. Este es el programa unido. Las líneas de import, class y main son la estructura externa necesaria para que Java sepa dónde está el código ejecutable.

  1. import java.util.Random;
  2. import java.util.Scanner;
  4. public class AdivinarNumero {
  5. public static void main(String[] args) {
  6. Scanner teclado = new Scanner(System.in);
  7. Random r = new Random();
  9. int secreto = r.nextInt(100) + 1;
  10. int intentos = 0;
  11. boolean adivino = false;
  13. System.out.println("Adiviná el número secreto entre 1 y 100.");
  15. while (intentos < 10 && !adivino) {
  16. System.out.println("Ingresá un número:");
  17. int numeroUsuario = teclado.nextInt();
  18. intentos = intentos + 1;
  20. if (numeroUsuario == secreto) {
  21. adivino = true;
  22. System.out.println("¡Correcto! Lo adivinaste en " + intentos + " intentos.");
  23. } else if (numeroUsuario < secreto) {
  24. System.out.println("El número secreto es mayor. Te quedan " + (10 - intentos) + " intentos.");
  25. } else {
  26. System.out.println("El número secreto es menor. Te quedan " + (10 - intentos) + " intentos.");
  27. }
  28. }
  30. if (!adivino) {
  31. System.out.println("Sin intentos. El número era " + secreto + ".");
  32. }
  34. teclado.close();
  35. }
  36. }

La última línea antes de cerrar, teclado.close();, significa: “cerrá el lector”. Se hace una sola vez, al terminar de pedir números.
